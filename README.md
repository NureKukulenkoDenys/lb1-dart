## Хід роботи

Створено консольний Dart-проєкт із поділом на модулі вхідних даних, розбору,
обробки колекцій та формування звіту. Для відображення альбому обрано
типізований Record замість класу, оскільки використання класів за умовою
першої лабораторної роботи заборонено, а Records дозволяють зберігати
інформацію з іменованими полями без втрати типобезпеки. Вхідний набір містить
25 CSV-подібних рядків, серед яких п'ять навмисно пошкоджені. Функція
`parseAlbum` перевіряє кількість полів і виконує числові перетворення через
`int.tryParse`, а дату — через `DateTime.tryParse` з додатковою перевіркою
канонічного вигляду, що запобігає прийняттю дат на зразок 30 лютого.
Функція `validateAlbum` окремо перевіряє бізнес-обмеження і повертає перелік
порушень, після чого `loadAlbums` формує список прийнятих записів та
повідомлення про помилки без аварійного завершення. Для обробки каталогу
реалізовано конвеєри `where`, `map` і `fold`, розрахунок сумарної тривалості
та середньої кількості треків, групування за лейблом у
`Map<String, List<Album>>` і агрегування даних у кожній групі. Результати
сортуються за роком та кількістю треків зі зміною напряму через іменований
параметр; під час побудови звіту застосовано `StringBuffer` та додаткові
параметри за замовчуванням. Окремо реалізовано замикання-фабрику фільтра,
перевірку каталожного коду регулярним виразом з іменованими групами,
маскування через `replaceAllMapped`, безпечний пошук через `firstOrNull`
і обчислення віку альбому через `DateTime.difference` та `Duration`.
Програму доповнено набором самодостатніх перевірок без сторонніх пакетів.

## Основні фрагменти реалізації

```dart
// where → map → fold: підсумовування тривалості.
return albums
    .where((Album album) => album.durationMinutes > 0)
    .map((Album album) => album.durationMinutes)
    .fold<int>(0, (int total, int minutes) => total + minutes);
```

```dart
// Замикання захоплює параметр minYear.
bool Function(Album) releasedFromYear(int minYear) {
  return (Album album) => album.year >= minYear;
}
```

```dart
// Регулярний вираз із іменованими групами.
final RegExp pattern = RegExp(r'^(?<prefix>ALB)-(?<number>\d{4})$');
```

У фактичному файлі `album_utils.dart` для цифр використано `\d{4}`
(один зворотний слеш у сирому рядку).

## Результати

У наборі з 25 рядків очікується 20 прийнятих альбомів і п'ять повідомлень
про помилки: відсутнє поле, нечисловий рік, неіснуюча дата, нуль треків,
неправильний код. Використання `fold` забезпечує коректну обробку порожньої
колекції. Статистика груп обчислюється незалежно для кожного лейбла.

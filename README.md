# Лабораторна робота №1 — каталог музичних альбомів

Варіант 8. Етап 1/5 (27.10.2026): створено проєкт і CSV-подібний набір даних.

- Дані містять 20 коректних і 5 спеціально пошкоджених рядків.
- Формат: `виконавець;назва;рік;лейбл;кількість треків;тривалість;дата;код`.
- Зовнішні залежності: немає, достатньо Dart SDK 3.13+.

Запуск: `dart pub get`, потім `dart run bin/music_album_catalog.dart`.
